# assets

Files read at build time by `src/app/opengraph-image.tsx` (the link preview card) and
`src/app/icon.tsx` (the tab icon). Satori, which draws both, needs TTF or OTF fonts, so these are
static TTF copies of the families the site itself loads through `next/font/google`.
